A make.fun entry for [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557): one line, 1 to 240 characters, giving the judge a quiet, earned moment of pride for someone in a scene.

## The entry

`main.ts` writes a single line to `/output/entry.txt` — an old fisherman who spent a year learning to read by lamplight, finally reading his grandson's birthday card aloud, his hands steady for once. A small person doing something hard, a long effort finally landing, told in one read with no trophy, no podium, no graduation.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
